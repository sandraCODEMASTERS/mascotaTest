Gestion de jornadas para tus mascotas

La alcaldia ofrece servicios gratuitos a los ciudadanos que se inscriban para jornadas de vacunacion y esterilizacion de sus mascotas. Las jornadas se habilitan para inscripcion segun disponibilidad de la alcaldia.

Crear cuenta Iniciar sesion

Que hace el sistema

Usuarios

Registro de ciudadanos

Los ciudadanos se registran con nombre, correo y una contrasena segura.

Mascotas

Registro de mascotas

Las mascotas son perros y gatos. El registro contiene nombre, especie y raza.

Servicios

Jornadas disponibles

Los usuarios registrados visualizan las jornadas de vacunacion y esterilizacion disponibles y envian solicitudes con una o varias de sus mascotas registradas.

Como funciona

  1. El ciudadano se registra en el sistema.
  2. Ingresa con su correo y contrasena.
  3. Registra sus mascotas (perros o gatos) con nombre, especie y raza.
  4. Consulta las jornadas de vacunacion y esterilizacion disponibles.
  5. Selecciona una o varias de sus mascotas y envia la solicitud de participacion.

Alcance del proyecto

Incluye

  • Aplicacion web en HTML, CSS y PHP.
  • Montaje en XAMPP.
  • Acceso a informacion persistente para identificacion y registro de usuarios.
  • Proyeccion de 50 usuarios activos no concurrentes.

No incluye

  • Notificaciones.
  • Reportes.
  • Transacciones.
Proyecto de prueba tipo academico Se mantiene todo simple. El sistema no envia notificaciones, no genera reportes y no realiza transacciones.
